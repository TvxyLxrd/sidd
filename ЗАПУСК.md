# SID Услуги — как запустить

Это маркетплейс цифровых услуг: сайт и сервер в одном. Отдельную базу данных ставить не нужно — всё работает сразу после запуска.

Времени на запуск: ~5 минут, из них 4 — установка Node.js.

---

## Шаг 1. Установить Node.js

Если он уже стоит — пропускайте шаг.

1. Откройте https://nodejs.org и скачайте версию **LTS** (большая зелёная кнопка).
2. Запустите установщик и жмите «Далее» до конца, ничего не меняя.
3. **Перезагрузите компьютер** или хотя бы закройте все открытые терминалы — иначе система не увидит новую программу.

Проверка: нажмите `Win + R`, введите `powershell`, Enter, и в открывшемся окне наберите:

```
node -v
```

Должна появиться строка вида `v22.11.0`. Если пишет «node не распознан как имя командлета» — Node не установился или вы не перезагрузились.

Нужна версия 18 или новее. Если вывелось что-то вроде `v14`, поставьте свежую с сайта поверх старой.

---

## Шаг 2. Распаковать проект

Распакуйте архив в любую папку, например `C:\Projects\Sid--Fullstack-main`.

**Важно:** не растаскивайте содержимое по разным местам. Внутри должна сохраниться такая структура:

```
Sid--Fullstack-main\
├── index.html, login.html, dashboard.html ...   ← страницы сайта
├── css\  js\
└── SID-Project-main\
    └── backend\        ← сервер
```

Сервер ищет страницы сайта на два уровня выше себя. Если папку `SID-Project-main` вынуть наружу, сайт перестанет открываться.

---

## Шаг 3. Запустить

Откройте PowerShell **в папке `backend`**. Проще всего так: зайдите в проводнике в `Sid--Fullstack-main\SID-Project-main\backend`, зажмите `Shift`, кликните правой кнопкой по пустому месту → «Открыть окно PowerShell здесь».

Или вручную из любого окна PowerShell (подставьте свой путь):

```
cd C:\Projects\Sid--Fullstack-main\SID-Project-main\backend
```

Дальше одна команда:

```
npm start
```

Первый запуск занимает 3–5 секунд. Готово, когда в окне появится:

```
Server running on port 3000
Web application: http://localhost:3000
```

Windows может один раз спросить про доступ к сети — можно смело нажать «Отмена», на работу это не влияет.

**Окно с сервером не закрывайте** — пока оно открыто, сайт работает.

---

## Шаг 4. Открыть сайт

В браузере: **http://localhost:3000**

Готовых учётных записей нет — площадка стартует пустой.

**Зарегистрируйтесь** через форму на сайте, чтобы войти как заказчик.

**Чтобы получить права администратора**, откройте второе окно PowerShell в той же папке `backend` и выполните:

```
npm run create-admin -- --email you@example.com
```

Команда напечатает сгенерированный пароль — скопируйте его сразу, второй раз он не покажется. После этого войдите с этими данными: откроется админ-панель со всеми заказами, пользователями и направлениями работы.

Под обычным пользователем доступны свои заказы, создание новых и профиль. Под администратором дополнительно открывается админка: все заказы, смена статусов, пользователи и направления работы.

---

## Как остановить

Нажмите `Ctrl + C` в окне с сервером или просто закройте это окно.

Учтите: **данные хранятся в памяти и стираются при каждом перезапуске**. После нового `npm start` база снова будет пустой: останутся только шесть направлений работы, а зарегистрированные пользователи и созданные заказы исчезнут. Это нормально, так задумано, чтобы не возиться с установкой PostgreSQL.

## Если что-то пошло не так

| Что видите | Что делать |
|---|---|
| `node не распознан` / `npm не распознан` | Node.js не установлен или не перезагрузились после установки — вернитесь к шагу 1 |
| `Cannot find module 'express'` | Пропала папка `node_modules`. Выполните в той же папке `npm install` и снова `npm start` |
| `EADDRINUSE: address already in use :::3000` | Сервер уже запущен в другом окне. Закройте его или выполните `Get-Process node \| Stop-Process -Force` |
| `ENOENT: schema.sql` | Проект скачан не целиком (частая беда при выгрузке через git — он вырезает `*.sql` и `.env`). Нужен именно архив с папкой целиком |
| Страница открывается пустой / «Не удалось выполнить запрос» | Проверьте, что окно с сервером ещё открыто и в нём нет красных строк |
| Все страницы отдают 404 | Нарушена структура папок — см. шаг 2 |
| Логин не проходит | Учётные записи пропадают при перезапуске сервера — зарегистрируйтесь заново или создайте администратора командой из шага 4 |

Подробности ошибок сервер пишет в файл `backend\logs\error.log`.

## Мелочи, которые могут пригодиться

- Порт 3000 занят чем-то другим? Откройте `backend\.env` блокнотом и поменяйте `PORT=3000` на, скажем, `PORT=4000` — тогда сайт будет на http://localhost:4000
- Проверить, что сервер жив, не открывая браузер: `curl http://localhost:3000/api/v1/health`
- Команда `npm run dev` запускает сервер в режиме разработки — он сам перезапускается при изменении кода
