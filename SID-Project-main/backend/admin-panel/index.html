🔐 Authentication

POST /auth/register

Регистрация нового пользователя

Request Body:
emailrequired string
passwordrequired string (min 6)
fullNamerequired string
phone string (optional)
Example Request: 
{
  "email": "user@example.com",
  "password": "securePassword123",
  "fullName": "John Doe",
  "phone": "+1234567890"
}
Example Response: 
{
  "success": true,
  "message": "User registered successfully",
  "data": {
    "user": {
      "id": "uuid",
      "email": "user@example.com",
      "fullName": "John Doe",
      "role": "user"
    },
    "tokens": {
      "accessToken": "jwt_token",
      "refreshToken": "refresh_token"
    }
  }
}

📋 Requests Management

GET /requests Auth Required

Получение списка заявок пользователя

Query Parameters:
status string (pending|in_progress|completed|rejected)
priority string (low|medium|high|urgent)
page number (default: 1)
limit number (default: 10)
POST /requests Auth Required

Создание новой заявки (лимит: 10/час)

Request Body:
titlerequired string (3-255)
descriptionrequired string (10-5000)
categoryIdrequired uuid
priority string (default: medium)
Example Request: 
{
  "title": "Проблема с авторизацией",
  "description": "Не могу войти в систему...",
  "categoryId": "uuid-category-id",
  "priority": "high"
}
GET /requests/:id Auth Required

PUT /requests/:id Auth Required

Обновление заявки

DELETE /requests/:id Auth Required

⚠️ Error Codes

Code Message Description
400 Bad Request Неверный формат запроса или валидация не пройдена
401 Unauthorized Требуется аутентификация или токен недействителен
403 Forbidden Недостаточно прав для выполнения операции
404 Not Found Ресурс не найден
429 Too Many Requests Превышен лимит запросов (Rate Limit)
500 Internal Server Error Внутренняя ошибка сервера
Error Response Format: 
{
  "success": false,
  "error": "Error message",

    }
  ]
}

  • ✅ Security event logging

🔑 Учётная запись администратора

Учётных записей по умолчанию нет. Администратор заводится явной командой — пароль генерируется и показывается один раз:

npm run create-admin -- --email you@domain.ru

# со своим паролем (не короче 12 символов):
npm run create-admin -- --email you@domain.ru --password "..."

Повторный запуск с тем же адресом меняет пароль и отзывает все ранее выданные сессии этого пользователя.
