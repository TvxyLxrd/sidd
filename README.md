# SID Услуги

Маркетплейс цифровых услуг: заказчик размещает заказ, площадка подбирает исполнителя и ведёт сделку до закрытия.

Приложение запускается одним сервером: он раздаёт HTML/CSS/JS и обслуживает REST API.

## Запуск

```powershell
cd .\SID-Project-main\backend
npm install
npm start
```

Откройте `http://localhost:3000`.

Учётных записей по умолчанию нет — база стартует пустой, в ней только справочник направлений работы. Зарегистрируйте заказчика через форму на сайте, а администратора заведите командой ниже.

## Администратор

```powershell
npm run create-admin -- --email you@domain.ru
```

Пароль генерируется и печатается один раз — сохраните его сразу. Можно задать свой, не короче 12 символов:

```powershell
npm run create-admin -- --email you@domain.ru --password "ваш-пароль"
```

Повторный запуск с тем же адресом меняет пароль и отзывает все ранее выданные сессии этого пользователя.

В режиме базы в памяти администратор создаётся при старте из `ADMIN_EMAIL` в `.env`. Если `ADMIN_PASSWORD` не задан, пароль генерируется на каждый запуск и выводится в журнал сервера.

## Режимы базы данных

По умолчанию в `.env` стоит `DB_DRIVER=memory`: PostgreSQL-совместимая база поднимается прямо в процессе, поэтому Docker не нужен. Данные такого режима исчезают при перезапуске — он только для разработки.

Для постоянного хранения укажите `DB_DRIVER=postgres`, заполните `DB_*` и выполните:

```powershell
npm run migrate
npm run seed
npm run create-admin -- --email you@domain.ru
npm start
```

## Перед публикацией

Полный порядок действий — в [PRODUCTION.md](SID-Project-main/PRODUCTION.md). Коротко:

```powershell
npm run generate-secrets
```

Подставьте выданные значения в `.env` вместе с `NODE_ENV=production` и `DB_DRIVER=postgres`. С ключами из шаблона сервер в боевом режиме не стартует — это сделано намеренно.

`ENCRYPTION_KEY` нельзя менять после первой записи данных: телефоны и тексты заказов шифруются, и без прежнего ключа они не расшифруются.

## Состав репозитория

| Путь | Что это |
|---|---|
| `index.html`, `css/`, `js/` | Веб-приложение, подключено к API |
| `SID-Project-main/backend/` | Сервер, база, защита данных |
| `SID-Project-main/frontend/` | Мобильное приложение на React Native |
| `SID-Project-main/PRODUCTION.md` | Чек-лист развёртывания |

Мобильное приложение пока не подключено к серверу: экраны собраны, но работают на локальном состоянии. Публиковать его в магазины в текущем виде нельзя.
